SYSTEM ARCHITECTURE · 2026-10-25 · V2.0.0

Reify 系统架构

当前架构是“逻辑分离、物理同源”的单机多用户平台：React SPA 由 FastAPI 同源托管，静态/React 走 /p/，Next 走独立 :12889 origin；React/Next 在 OpenSandbox 内构建，Next 额外拥有运行时沙箱。目标架构把每个项目放进自己的最轻量沙箱，由运行时网关按项目路由，形成“一次项目 = 一次小部署”。

01 · CURRENT

当前运行架构

已实现 · v2.0.0

静态与 React 产物由平台进程直接托管；Next 在独立运行时沙箱中提供服务。构建沙箱与运行时沙箱都不继承平台密钥，平台容器不持有 docker.sock。

02 · TARGET

目标部署架构：每项目独立轻量沙箱

规划中 · 未上线

把静态、React、Next 统一为“构建 → 不可变产物 → 项目沙箱 → 健康检查 → 网关路由”的部署模型。每个项目拥有独立的轻量沙箱、独立 origin 与独立生命周期；平台只保留控制面与产物索引。
